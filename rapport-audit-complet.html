3. Critiques (4/4 CORRIGES)

CRITIQUE C1 - Middleware IdempotencyMiddleware manquant

Fichier freipay-users/bootstrap/app.php importait un middleware inexistant. Erreur 500 sur POST /users/me/accounts.

Correction : CORRIGE Fichier cree.

CRITIQUE C2 - Hashes bcrypt exposes dans le SQL dump

Le dump contenait des hashes bcrypt de mots de passe admin et OTP.

Correction : CORRIGE Remplaces par HASH_ANONYMIZED_001/002.

CRITIQUE C3 - CORS wildcard * dans le gateway

Le gateway autorisait * pour les origines CORS. Risque CSRF et vol de tokens.

Correction : CORRIGE Origines restreintes via FRIPAY_CORS_ORIGINS.

CRITIQUE C4 - Injection SQL dans TransferController.sort

Le parametre sort etait utilise directement dans orderBy() sans validation.

Correction : CORRIGE Whitelist : initiated_at, amount, status, completed_at.
